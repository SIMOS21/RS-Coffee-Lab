# Prompt réutilisable — un ticket par exécution

Implémente **uniquement le ticket `[REMPLACER PAR T-XXX]`** de `tasks/TASKS.md` dans ce dépôt.

- Respecte `AGENTS.md` et lis les documents référencés par le ticket.
- Inspecte l'existant et confirme les prérequis ; n'écrase pas du travail sans le lire.
- Identifie les fichiers impactés et les critères d'acceptation AVANT de coder.
- Implémente avec tests de sécurité, robustesse, UX et documentation proportionnés.
- Ne crée pas de faux contenus business ni de fonctionnalité payante/production non approuvée.
- Lance lint, typecheck, tests, build et E2E appropriés. Si un test n'a pas pu tourner, indique clairement pourquoi.
- Mets à jour le statut de ce ticket dans `tasks/TASKS.md` avec résultats et limitations.
- Termine avec une synthèse structurée, puis propose le ticket suivant sans le commencer.
